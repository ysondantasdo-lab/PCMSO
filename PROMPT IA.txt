Como um programador experiente em javascript me ajude.
O programa será feito em javascript usando o Node.js.
Eu quero fazer um programa usando o VSCode como editor de código.
Estou com o Node.js instlado em minha máquina.
Eu não tenho o Excel instalado no meu computador somente o LibreOffice.
Este programa é da área de Segurança do Trabalho. 
Ele deve pegar as informações em uma planilha do Excel que tem os dados dos riscos do PGR e organizar as informações em uma planilha no LibreOffice Calc para facilitar para a médica do trabalho fazer o PCMSO. 
O que o programa deve fazer:
O programa deve ler as informações em uma planilha no Excel que será indicada pelo usuário através de uma janela para informar local do arquivo.
As informações lidas são as que estão nas colunas com cabeçalho: A (ÓGÃO / SECRETARIA), B ( SETOR/LOTAÇÃO), D (CARGO/FUNÇÃO), H (DESCRIÇÃO CARGO/FUNÇÃO), I (AGENTES / RISCOS AMBIENTAIS), J (FATOR DE RISCO AMBIENTAL), K (FONTE GERADORA), M(DANOS A SAUDE), N(TIPO DE EXPOSIÇÃO).
Este programa deve obter e organizar os dados obtidos nas colunas mencionadas.
O objetivo da organização dos dados é encontrar e agrupar os grupos homogêneos de exposição aos riscos, pois o PCMSO indica exames iguais para as pessoas que estão expostas aos mesmos riscos.
Agrupamento:
O agrupamento deve ser de todos os dados em que a coluna I (AGENTES / RISCOS AMBIENTAIS) e a coluna N(TIPO DE EXPOSIÇÃO) forem iguais.
Deve ser inserido uma nova coluna inicial e nesta coluna vamos identificar os grupos homogêneos começando pelo GH 01. Exemplo para o primeiro grupo em que a coluna I e N são iguais colocar em cada linha da nova coluna A = "GH01" para o segundo grupo em que a coluna I e N são iguais colocar na nova coluna A = "GH02".
É preciso colorir todas as células em que possuem o mesmo grupo homogêneo informado na nova Coluna A.
Para facilitar a visualização dos diferentes grupos homogêneos usar cores significativamente diferentes para cada grupo homogêneo.
Por exemplo: Para GH01 - linhas cor verde, GH02 - linhas cor amarela, GH03 - linhas cor vermelha. etc.
